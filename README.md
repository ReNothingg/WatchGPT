# WatchGPT ⌚️

ChatGPT на Apple Watch **по вашей подписке ChatGPT** (Plus / Pro / Business), без API-ключа.
Нажали на микрофон, продиктовали, получили ответ. Сразу видно, сколько осталось от лимита.

- 🎙 **Один тап**: микрофон → диктовка → ответ печатается в реальном времени
- 🔋 **Лимиты**: кольцо в углу и экран «Лимиты» показывают остаток в 5-часовом и недельном окне и время сброса
- 🧠 **Выбор модели** и глубины размышления (список моделей приходит с сервера ChatGPT)
- 🌐 Поиск в интернете, 🔊 чтение ответа вслух, режим коротких ответов
- 🧩 **Виджет** для Smart Stack и циферблата: один тап — и сразу диктуете вопрос
- 📱 **Вход по QR-коду**: сканируете iPhone'ом, входите в ChatGPT, вводите код с часов

## Как это работает

Приложение входит в аккаунт ChatGPT тем же способом, что и официальный
[Codex CLI](https://github.com/openai/codex) (`codex login --device-auth`), и отправляет
запросы на тот же сервер, что и Codex. Поэтому:

- оплачивать API не нужно — всё идёт **в счёт подписки ChatGPT**;
- лимиты **общие с Codex** (именно их показывает приложение);
- это **неофициальный** способ: OpenAI может в любой момент его изменить, и тогда
  приложение перестанет работать, пока его не обновят. Используйте на свой риск.

Токены хранятся только в Keychain часов. Переписка не сохраняется на серверах (`store: false`),
а на часах хранится только текущий чат.

## Что нужно

- Mac с **Xcode 16** или новее
- Apple Watch с **watchOS 10** или новее, сопряжённые с iPhone
- Apple ID (подойдёт бесплатный) — см. «Бесплатный или платный аккаунт» ниже
- Подписка ChatGPT

## Установка на часы через Xcode

1. **Склонируйте репозиторий** и откройте `WatchGPT.xcodeproj`.
2. **Укажите уникальный Bundle ID.** Выберите проект *WatchGPT* (синяя иконка слева) →
   вкладка *Build Settings* → найдите `BUNDLE_ID_BASE` → замените `com.example.watchgpt`
   на своё, например `com.ivan.watchgpt`.
3. **Подпись.** *Signing & Capabilities* → для **обеих** целей (`WatchGPT` и
   `WatchGPTWidget`) выберите свою команду (*Team*). Если Apple ID ещё не добавлен:
   *Xcode → Settings → Accounts → +*.
4. **Включите режим разработчика:**
   - на iPhone: *Настройки → Конфиденциальность и безопасность → Режим разработчика*;
   - на часах: подключите их к Xcode (iPhone по кабелю, часы рядом и разблокированы),
     затем на часах *Настройки → Конфиденциальность и безопасность → Режим разработчика*.
5. Вверху Xcode выберите схему **WatchGPT** и ваши часы как устройство → **Run (⌘R)**.
   Первая установка на часы может занять несколько минут.

> Если Xcode ругается на **App Groups** при подписи (бывает с бесплатным аккаунтом),
> удалите возможность *App Groups* в *Signing & Capabilities* у обеих целей.
> Всё будет работать, только виджет не будет показывать процент лимита.

## Первый запуск: подключение ChatGPT

1. Откройте WatchGPT на часах — появятся **QR-код** и короткий **код** (например, `ELVZ-J018F`).
2. Наведите камеру iPhone на QR → откроется `auth.openai.com/codex/device`.
3. Войдите в свой аккаунт ChatGPT и введите код с часов.
4. Часы сами подхватят вход (обычно за пару секунд).

Если пишет, что **вход по коду недоступен**: на сайте ChatGPT откройте
*Настройки → Безопасность* и включите вход по коду устройства для Codex
(*device code authorization*). В рабочих аккаунтах (Business/Enterprise) это включает администратор.

## Как пользоваться

- **Главный экран** — большая зелёная кнопка микрофона. Нажмите, продиктуйте, отправьте:
  ответ появится сразу, часы коротко вибрируют, когда он готов.
- **Кольцо слева вверху** — сколько процентов лимита осталось (по самому «узкому» окну).
  Нажмите, чтобы увидеть оба окна (5 ч и неделя) и время сброса.
- **Нижняя панель в чате**: ✏️ новый чат · 🎙 следующий вопрос · 🔊 прочитать ответ.
  Двойное касание ответа тоже читает его вслух.
- **Настройки** (кнопка справа вверху): модель, глубина размышления, поиск в сети,
  короткие ответы, автоозвучка, выход из аккаунта.
- Чат хранит контекст: можно задавать уточняющие вопросы. Через 6 часов без активности
  начинается новый чат.

## Виджет

- **Smart Stack**: на циферблате прокрутите Digital Crown вверх → долгое нажатие →
  *+* → WatchGPT → «Спросить ChatGPT».
- **Усложнение на циферблате**: долгое нажатие на циферблат → *Изменить* → выберите место → WatchGPT.

Виджет показывает остаток лимита и открывает приложение сразу на диктовку.

## Структура проекта

```
WatchGPT/            приложение для часов
  App/               точка входа
  Auth/              вход через ChatGPT по коду устройства, токены, Keychain
  API/               клиент ChatGPT: стриминг ответов, лимиты, список моделей
  Store/             состояние чата и настроек
  Views/             экраны: чат, вход по QR, настройки, лимиты
  Support/           генератор QR, диктовка, озвучка
WatchGPTWidget/      виджет (Smart Stack и усложнения)
Shared/              общее для приложения и виджета
project.yml          описание проекта для XcodeGen
```

`WatchGPT.xcodeproj` уже сгенерирован. Если меняете `project.yml`, пересоберите проект:
`brew install xcodegen && xcodegen generate`.

## Если что-то не работает

- **«Нужно заново войти в ChatGPT»** — *Настройки → Выйти* и подключитесь снова.
- **«Лимит исчерпан»** — дождитесь сброса (время видно на экране «Лимиты»).
- **Нет списка моделей / ошибка 4xx при ответе** — возможно, сервер ждёт более новую
  версию клиента Codex. Поменяйте `clientVersion` в `WatchGPT/API/ChatGPTClient.swift`
  на номер последнего релиза [Codex](https://github.com/openai/codex/releases).
- **Нет интернета** — часам нужна связь через iPhone, Wi-Fi или LTE.
